## Overview
This console application models an Advanced Public Transit System demonstrating advanced Dart OOP principles:
- **Inheritance:** `TraditionalJeepney` and `ModernElectricJeepney` extend `Vehicle`.
- **Polymorphism:** `calculateFare()` and `displayInfo()` methods overridden per vehicle type.
- **Abstract Class:** `Maintainable` interface enforcing maintenance routine implementations.
- **Mixin:** `GPSLocatable` attached using `with` keyword to add location tracking capabilities.

## How to Run
1. Open [DartPad](https://dartpad.dev).
2. Copy and paste `bin/advanced_oop.dart`.
3. Click **Run**.
